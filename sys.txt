PROMPT MAESTRO — TRIPCANVAS
1. ROL

Actúa como un ingeniero de software senior especializado en aplicaciones web, UI/UX, generación de contenido con IA y herramientas para creación de contenido visual para redes sociales.

Debes desarrollar una aplicación web llamada TripCanvas.

No quiero solamente una demo visual. Quiero construir una aplicación con una arquitectura limpia, modular y preparada para crecer.

Antes de implementar funcionalidades complejas, analiza la arquitectura existente del proyecto y mantén una estructura organizada.

2. CONCEPTO DEL PROYECTO

TripCanvas será una plataforma web para crear automáticamente tarjetas informativas y contenido visual sobre destinos turísticos, inicialmente enfocado en Perú.

El usuario podrá:

Seleccionar un destino turístico.
Elegir un tipo de contenido.
Indicar cuántas tarjetas quiere generar.
Utilizar Google Gemini para generar el contenido.
Revisar y editar el contenido.
Seleccionar una plantilla visual.
Personalizar colores, tipografías, imágenes y elementos.
Ver una previsualización en tiempo real.
Exportar las tarjetas como PNG/JPG.
Generar varias tarjetas y descargarlas juntas.
Guardar proyectos para editarlos posteriormente.

La aplicación debe sentirse como una mezcla entre:

Canva
un generador de contenido con IA
un editor de tarjetas para redes sociales
una herramienta especializada en turismo

Pero no debe copiar visualmente ninguna de estas plataformas.

15. GEMINI

Gemini debe utilizarse principalmente para generar contenido estructurado.

NO pedirle que genere HTML.

NO pedirle que genere CSS.

NO permitir que controle directamente el diseño.

Gemini solamente devuelve datos.

16. FORMATO DE RESPUESTA DE GEMINI

La respuesta debe ser JSON válido.

Ejemplo:

{
"destination": "Machu Picchu",
"cards": [
{
"type": "dato_curioso",
"title": "¿Sabías que Machu Picchu permaneció oculta durante siglos?",
"body": "La ciudadela permaneció prácticamente desconocida para el mundo exterior durante siglos.",
"facts": [],
"location": "Cusco, Perú",
"altitude": "2430 m s. n. m.",
"source": "UNESCO"
}
]
}

Nunca depender del texto libre para procesar la respuesta.
